<h1 align="center">Tux-Force</h1>
<p align="center"><b>The PC games you own or subscribe to, on Linux. Real licenses, no cracks.</b></p>

Tux-Force brings Xbox PC (GDK) games to Linux the legal way: you sign in with your own Microsoft account, licenses come
from Microsoft's licensing service, and only what your account is entitled to will start.

**Website: [tux-force.github.io](https://tux-force.github.io)** with the
[quick start](https://tux-force.github.io/guide/quick-start/),
[compatibility list](https://tux-force.github.io/compatibility/) and
[downloads](https://tux-force.github.io/downloads/).

## Why Tux-Force

- **A whole ecosystem, not a single tool.** Runtime, Wine, sign-in and downloads today; a graphical launcher with
  library and store view, automatic prefix setup and a community compatibility list next.
- **AI welcome.** Tux-Force is developed with AI tools in the open, and AI-assisted contributions are welcome. What
  counts is a tested result. See [Contributing](https://tux-force.github.io/project/contributing/).
- **Our own pace.** The core repositories are forks of the xodus-gaming projects. We pull in new upstream code when it
  helps, credit it everywhere and otherwise develop independently.

## Repositories

| Repository | What it is | Upstream |
|---|---|---|
| [xTux](https://github.com/Tux-Force/xTux) | Sign-in, licenses, downloads, game start, bridge for GDK services | [xodus-gaming/xodus](https://github.com/xodus-gaming/xodus) |
| [xgameruntime](https://github.com/Tux-Force/xgameruntime) | Open source `xgameruntime.dll` (GDK runtime) for Wine | [xodus-gaming/xgameruntime](https://github.com/xodus-gaming/xgameruntime) |
| [wine](https://github.com/Tux-Force/wine) | Wine tree with the runtime and fixes for GDK games | [xodus-gaming/wine](https://github.com/xodus-gaming/wine) |
| [tux-force.github.io](https://github.com/Tux-Force/tux-force.github.io) | The website: guide, compatibility list, downloads, news, vision, roadmap, brand | |

## Status

Farming Simulator 25 plays, including saves, ModHub and Xbox Live. Microsoft Flight Simulator 2024 signs in and reaches
its services. Expect rough edges: this is early software.
